# Ontology RAG Deep Validation Skill

## 概述
执行 ontology RAG 深度验证，用于运营分析。验证 RAG 系统对运营数据的理解能力和推理深度。

## 核心能力
- 运行运营分析的深度 RAG 验证
- 测试运营数据推理准确性
- 验证复杂场景下的 RAG 表现

## 使用方法

```bash
python scripts/diagnostics/run_ops_deep_rag.py
```

## 输入输出
- **输入**: 自动使用默认配置
- **输出**: 深度验证报告、推理质量指标

## 配置
默认从项目配置中读取 RAG 参数和运营数据路径。
